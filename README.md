# ALL Playlist 🎵

A responsive Hindi-first playlist discovery site inspired by the visual language of the reference shown during development. Built from scratch with React, TypeScript and Vite.

## Features

- Illustrated hero section
- Featured playlist section
- Category filters
- Responsive playlist card grid
- External playlist links
- Add-your-site modal with URL validation
- Mobile-first responsive behavior
- Netlify-ready deployment configuration

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Deploy

The repository includes `netlify.toml`. Import this repository into Netlify and use the default settings; the build command is already configured.

## Content

Playlist metadata lives in `src/data/playlists.ts`, so adding or editing playlist cards does not require changing the UI components.
